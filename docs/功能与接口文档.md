# AI 旅行规划小程序 —— 功能与接口文档


后端地址（本地开发）：`http://localhost:8080`

---

## 一、项目简介

用户输入「城市 / 喜好 / 预算 / 天数 / 体力」等，AI 结合小红书、B站等真实口碑 + 本地知识库，自动生成「每日行程 + 地图路线」攻略。

AI 能力

| 能力 | 说明 |
|------|------|
| 大模型 | DeepSeek 生成攻略 |
| 智能体 | Function Calling，自主调用「联网搜索 / 知识库检索 / 地理编码」3 个工具 |
| RAG | Zilliz 向量库 + 硅基流动 embedding，按城市过滤检索（越用越聪明） |
| AI 工作流 | 7 步编排：校验 → RAG检索 → Agent → 生成 → 反思 → 地理编码 → 持久化+摄入 |
| 流式输出 | SSE 边生成边显示 |
| 用户记忆 | 记住历史偏好，个性化推荐 |

---

## 二、页面

### 页面流程

```
登录页 → 表单页 → 生成中/结果页 → 历史列表页 → 详情页
```

### 1. 表单页（用户输入）

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| 城市 | 文本 | ✅ | 目的地，如「杭州」 |
| 喜好 | 多选 tag + 自由文字 | 否 | 人文 / 自然 / 美食 / 网红 / 购物 / 亲子 等 |
| 总预算 | 文本 | 否 | 全程总预算，如「3000元」 |
| 天数 | 数字 | ✅ | 1–15 天 |
| 体力 | 三选一 | 否 | 轻松（老人/带娃）/ 适中 / 充沛（特种兵） |
| 其他需求 | 自由文本 | 否 | 如「带 2 岁小孩」「对海鲜过敏」「要能停车」 |

### 2. 结果页（核心输出）

- **每日行程**：按「天」Tab 切换
  - 每天包含：主题标题、景点列表（名称 / 推荐理由 / 避坑提示 / 游玩时长 / 交通方式 / 坐标）、美食推荐、当天注意事项
- **地图**（前端渲染）：后端只返回每个景点的 `lat/lng` 坐标，地图打点（markers）和路线连线（polyline）由前端用腾讯地图小程序 SDK 完成
- **整体**：行程概览、整体避坑清单、信息来源

### 3. 历史列表页

- 每条只显示：**标题（如「杭州 3天」）+ 创建时间**
- 支持左滑/按钮删除

### 4. 详情页

- 展示某次行程的完整攻略

## 三、API 接口文档

### 统一返回格式

```json
{ "code": 0, "message": "ok", "data": { } }
```

- `code = 0` 成功；非 0 失败
- 错误码：`401` 未登录/token 无效 · `400` 参数错误 · `404` 不存在 · `500` 服务器错误 · `502` 第三方(AI/搜索/向量库)调用失败
- `data` 为具体数据（失败时无 `data`）

### 认证说明

- 除「登录」外，所有接口请求头都要带：`Authorization: Bearer <token>`
- `token` 由登录接口返回，或前端拿到后存本地 storage

---

### 1. 登录

```
POST /api/auth/login
```

**请求体**
```json
{ "code": "微信 wx.login() 拿到的临时 code" }
```

**成功响应**
```json
{
  "code": 0,
  "data": {
    "token": "eyJhbGciOiJIUzI1NiJ9...",
    "user": { "id": 1, "openid": "xxx", "nickname": null, "avatarUrl": null }
  }
}
```

**失败响应（code 无效）**
```json
{ "code": 401, "message": "微信登录失败: invalid code" }
```

---

### 2. 生成攻略（流式 SSE）

```
POST /api/trip/generate/stream
```

**请求体**
```json
{
  "city": "杭州",
  "preferences": "美食、自然",
  "budget": "3000",
  "days": 3,
  "energyLevel": "medium",
  "extra": "带爸妈，节奏慢一点"
}
```

字段说明：`energyLevel` 取 `easy` / `medium` / `hard`；其余字段均可选（`city`、`days` 必填）。

返回 `text/event-stream`，事件格式为 `{ "type": "...", "data": ... }`：

| type | data | 说明 |
|------|------|------|
| `step` | 字符串 | 进度提示，如「正在搜索：杭州 美食」 |
| `token` | 字符串 | 攻略 JSON 生成中的文本片段（前端逐字拼接显示） |
| `done` | `{ "tripId": 1 }` | 生成完成 |
| `error` | 字符串 | 出错信息 |

微信小程序用 `wx.request` 的 `enableChunked: true` + `onChunkReceived` 接收。

**前端对接流程**
1. 收到 `token` 片段逐字拼接显示（typewriter 效果）
2. 收到 `done` 里的 `tripId` 后，调 `GET /api/trip/{tripId}` 获取最终完整攻略（含 `lat/lng` 坐标，用于地图打点）

**最终攻略 JSON 结构**（即 `/api/trip/{id}` 详情返回的 `result`）
```json
{
  "city": "杭州",
  "overview": "整体行程概览...",
  "days": [
    {
      "day": 1,
      "title": "西湖经典线",
      "theme": "城市地标",
      "spots": [
        {
          "name": "西湖",
          "reason": "推荐理由",
          "tip": "避坑提示",
          "duration": "3小时",
          "transport": "地铁1号线",
          "lat": 30.25,
          "lng": 120.15
        }
      ],
      "food": [ { "name": "西湖醋鱼", "reason": "推荐理由" } ],
      "note": "当天注意事项"
    }
  ],
  "tips": ["整体避坑建议"],
  "sources": [ { "title": "来源标题", "url": "链接", "site": "小红书" } ]
}
```

`lat`/`lng` 由后端通过腾讯地图自动补全，前端直接用这两个字段在地图上打点。

### 3. 历史列表

```
GET /api/trip/list
```

**成功响应**（只返回摘要，不含完整攻略）
```json
{
  "code": 0,
  "data": [
    { "id": 2, "title": "杭州 5天", "createdAt": "2026-09-16T18:32:00" },
    { "id": 1, "title": "杭州 3天", "createdAt": "2026-09-16T17:00:00" }
  ]
}
```

---

### 4. 行程详情

```
GET /api/trip/{id}
```

**成功响应**：返回单条完整行程，`data` 里包含 `result`（完整攻略 JSON，结构同「生成攻略」里的 `result`）。

```json
{
  "code": 0,
  "data": {
    "id": 1,
    "city": "杭州",
    "preferences": "美食、自然",
    "budget": "3000",
    "days": 3,
    "energyLevel": "medium",
    "extra": "带爸妈",
    "status": "done",
    "result": { "...完整攻略 JSON..." },
    "createdAt": "2026-09-16T17:00:00"
  }
}
```

---

### 5. 删除行程

```
DELETE /api/trip/{id}
```

**成功响应**
```json
{ "code": 0, "message": "ok", "data": null }
```

## 四、前端对接要点（Tips）

1. **登录**：`wx.login()` 拿 code → 调 `/api/auth/login` → 存 `token`。
2. **生成**：表单提交给 `/api/trip/generate/stream`（流式，边生成边显示）；收到 `done` 的 `tripId` 后调 `/api/trip/{id}` 拿最终结果。
3. **结果页**：用 `result.days[].spots[].lat/lng` 在地图打点，`polyline` 串起当日路线。（地图渲染是前端用腾讯地图**小程序 Key** 完成）
4. **历史列表**：调 `/api/trip/list`，用 `title` 显示，点进去调 `/api/trip/{id}`。
5. **删除**：调 `DELETE /api/trip/{id}`。

## 五、体力档位约定

| 值 | 含义 |
|----|------|
| `easy` | 轻松（老人 / 带小孩，减少景点、放慢节奏） |
| `medium` | 适中（默认） |
| `hard` | 充沛（年轻人 / 特种兵，行程更满） |
